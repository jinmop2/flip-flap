개인정보 처리방침

FLIP FLAP (flip-flap.onrender.com) · 시행일 2026년 9월 2일

FLIP FLAP(이하 “게임”)은 이용자의 개인정보를 소중히 다룹니다. 이 방침은 게임이 무엇을 모으고, 왜 모으고, 언제까지 두는지를 적어 둔 것입니다.

게임은 광고 네트워크·분석 도구를 쓰지 않습니다. 접속 통계는 게임 서버가 직접 세며, 그 수치는 날짜별 합계(방문 수·게임 수 등)뿐이라 개인을 가리키지 않습니다.

구분항목모으는 때

2. 쓰는 곳

  • 게임 진행 — 로그인 유지, 전적·재화·아이템 저장, 랭킹 표시
  • 어뷰징 방지 — 기기 지문은 한 사람이 계정을 여럿 만들어 초대 보상을 반복 수령하는 것을 막는 데만 씁니다
  • 운영 — 신고 처리, 이용 제한, 문의 응대
  • 서비스 개선 — 날짜별 합계 통계로 어느 모드가 많이 쓰이는지 봅니다

위 목적 밖으로는 쓰지 않으며, 어떤 경우에도 판매하지 않습니다.

이용자 정보를 제3자에게 제공하지 않습니다. 다만 게임이 도는 데 아래 업체의 설비를 씁니다.

4. 얼마나 두는가

  • 계정 정보·게임 기록 — 탈퇴할 때까지. 탈퇴하면 바로 지웁니다(복구 불가)
  • 로그인 토큰 — 30일. 지나면 다시 로그인해야 합니다
  • 채팅·쪽지 — 최근 것 위주로 일정 개수만 남기고 오래된 것부터 지웁니다
  • 신고 기록 — 최근 것 위주로 보관하며 운영 판단이 끝나면 지웁니다
  • 접속 통계 — 날짜별 합계만 남습니다(개인 식별 불가)
  • 순방문 판단용 IP — 서버 메모리에만, 자정(KST)에 사라집니다

5. 이용자가 할 수 있는 것

  • 보기·고치기 — 게임 안 내 정보에서 닉네임·프로필을 보고 바꿀 수 있습니다
  • 탈퇴(전부 삭제) — 게임 안 내 정보 → 계정 삭제에서 직접 지울 수 있습니다. 전적·코인·아이템·칭호가 모두 사라지며 되돌릴 수 없습니다
  • 문의 — 아래 연락처로 요청하시면 확인 후 처리합니다

6. 안전하게 두기 위해 하는 것

  • 비밀번호는 원문을 저장하지 않습니다. 계정마다 다른 소금을 섞어 scrypt로 해시만 남깁니다
  • 접속 IP는 원문 대신 되돌릴 수 없는 해시로만 남깁니다
  • 모든 통신은 HTTPS로 암호화됩니다
  • 운영자 기능은 별도 키로 잠겨 있고, 무엇을 했는지 기록이 남습니다
  • 서버 접근 요청 수를 제한해 무차별 대입을 막습니다

7. 어린이

만 14세 미만은 법정대리인의 동의 없이 가입할 수 없습니다. 만 14세 미만임이 확인되면 해당 계정을 지웁니다.
