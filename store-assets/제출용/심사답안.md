# 심사 서류 답안지

앱이 실제로 하는 일을 기준으로 적었습니다. 코드를 훑어 확인한 것이고,
답이 처리방침(/privacy)과 어긋나면 반려되므로 그대로 쓰시면 됩니다.

## 1. 데이터 보안 (Data safety)

### 수집하는가 → 예

| 항목 | 수집 | 공유 | 필수 | 목적 |
|---|---|---|---|---|
| 이름 (닉네임) | ○ | × | 필수 | 앱 기능 (다른 이용자에게 보임) |
| 사용자 ID | ○ | × | 필수 | 앱 기능·계정 관리 |
| 기타 사용자 생성 콘텐츠 (채팅·쪽지) | ○ | × | 선택 | 앱 기능 |
| 앱 상호작용 (게임 기록·전적) | ○ | × | 필수 | 앱 기능 |
| **기기 또는 기타 ID** | ○ | **○** | 선택 | **광고 또는 마케팅** · 앱 기능(알림) |

> **기기 또는 기타 ID 는 "예" 로 답해야 합니다.** 앱에 AdMob 이 들어 있어
> 광고를 고르는 데 기기의 광고 ID 를 씁니다. 게임 서버가 그 값을 받지는
> 않지만, 앱 안에서 도는 SDK 가 모으면 수집으로 신고해야 합니다.
> 알림을 켜면 파이어베이스 기기 토큰도 저장합니다(기기 다섯 대까지).

### 수집하지 **않는** 것 — 전부 "아니요"
이름(실명) · 이메일 · 전화번호 · 주소 · 위치 · 사진 · 동영상 · 오디오 ·
연락처 · 캘린더 · 파일 · 건강 · 금융 정보 · 결제 정보 ·
앱 성능 진단 · 검색 기록 · 설치된 앱

> IP는 되돌릴 수 없는 해시 16자만 남기고 원문을 저장하지 않습니다.
> 소셜 로그인에서 이메일·전화번호·프로필 사진을 받지 않습니다 — 달라고 하지
> 않습니다. 구글은 `openid profile`, 애플은 `name` 만 요청합니다.
> 받는 것은 고유 식별자(sub)와 표시 이름뿐이고, 이름이 없으면 '플레이어' 로
> 시작해 본인이 첫 로그인에서 닉네임을 정합니다.

### 보안 관련
| 질문 | 답 |
|---|---|
| 전송 중 암호화 | **예** (전 구간 HTTPS) |
| 삭제 요청 가능 | **예** (앱 안 내 정보 → 계정 삭제) |
| 독립 보안 검토 | 아니요 |

## 2. 콘텐츠 등급 (IARC 설문)

| 질문 | 답 | 근거 |
|---|---|---|
| 폭력 | **없음** | 카드 게임. 유혈·전투 묘사 없음 |
| 성적 콘텐츠 | **없음** | |
| 언어 (욕설) | **없음** | 앱이 욕설을 담지 않음 |
| 통제 약물 | **없음** | |
| 공포 | **없음** | |
| **모의 도박** | **아니요** | 미니게임(섯다식 배팅)은 **잠겨 있다.** 화면의 단추를 지운 것만이 아니라 서버가 그 모드를 아예 안 받는다(`PICKABLE_MODES`). 소켓으로 직접 불러도 "알 수 없는 모드" 로 거절된다 — 시험(t_minilock)이 실제로 불러 보고 확인한다. **되살릴 때는 이 답도 같이 바꿔야 한다** |
| 실제 도박 (현금 획득) | **아니요** | 코인은 현금으로 바꿀 수 없고 살 수도 없다 (약관 2조) |
| 확률형 아이템(루트박스) | **예** | 뽑기 있음. 확률을 게임 안과 /rates 에 공개 |
| 이용자 간 소통 | **예** | 클랜 채팅·친구 쪽지·이모트. 신고·차단·운영자 제재 기능 있음 |
| 이용자 위치 공유 | 아니요 | |
| 개인정보 공유 | 아니요 | |
| 디지털 구매 | **아니요** | 현재 결제 없음 |

> ⚠ **여기가 이 앱에서 제일 조심할 자리입니다.**
>
> · 모의 도박 — 미니게임을 **잠갔으므로 아니요** 입니다. 다만 잠근 것이 화면
>   단추만이 아니라 서버까지여야 이 답이 사실이 됩니다(`PICKABLE_MODES`).
>   **미니게임을 되살리는 날 이 답도 반드시 같이 바꿔야 합니다** — 아니요로
>   답했다가 나중에 드러나면 등급 재조정이 아니라 앱이 내려갑니다.
>
> · 확률형 아이템 — "가상 화폐로 구매" 는 예로 답해야 하지만,
> "현금으로 바꿀 수 있음" 은 반드시 **아니요** 입니다. 약관 2조에 그렇게 적어 뒀습니다.
>
> · 광고 — **예** 입니다. 보상형만 넣었고 이용자가 눌러야 나옵니다.
>   데이터 보안의 "기기 또는 기타 ID" 도 같이 예로 바뀝니다(위 1항).

## 4. 앱이 요구하는 권한 — 심사 때 물으면

아래는 빌드된 매니페스트에서 그대로 뽑은 것입니다. 우리가 직접 적은 것은
INTERNET 하나뿐이고, 나머지는 구글 SDK 들이 합쳐 넣습니다.

| 권한 | 넣은 것 | 왜 |
|---|---|---|
| INTERNET | 우리 | 온라인 대전 |
| ACCESS_NETWORK_STATE | Capacitor | 연결이 끊겼는지 본다 |
| **POST_NOTIFICATIONS** | 파이어베이스 | **알림을 보낸다.** 이용자가 설정에서 켰을 때만 — 친구 신청·쪽지·대전 차례 |
| WAKE_LOCK · FOREGROUND_SERVICE | 파이어베이스 | 알림을 받는 데 쓴다 |
| **com.google.android.gms.permission.AD_ID** | AdMob | **광고 ID.** 데이터 보안의 "기기 또는 기타 ID" 가 예인 이유다 |
| ACCESS_ADSERVICES_AD_ID | AdMob | 안드로이드 광고 서비스(Privacy Sandbox) |
| ACCESS_ADSERVICES_ATTRIBUTION | AdMob | 광고 성과 측정 |
| ACCESS_ADSERVICES_TOPICS | AdMob | 관심사 기반 광고 |

> **결제(`com.android.vending.BILLING`) 권한은 들어 있지 않습니다.**
> TWA 시절 답안에 적혀 있던 것이라 지웠습니다 — 지금 빌드에는 없고,
> 인앱 구매도 "아니요" 로 답합니다.

## 5. 미니게임 — 따로 짚어 둘 것

미니게임은 **섯다식 배팅 게임**입니다. 이름만 미니게임이지 구조는 포커에 가깝습니다.

| | |
|---|---|
| 자리값 | 코인 200 (1코인 = 10달) |
| 앉을 조건 | 코인 20 이상 |
| 배팅 | 앤티 · 삥 · 하프 · 쿼터 · 따당 · 콜 · 체크 · 폴드 · 올인 |
| 정산 | 일어설 때 남은 달을 코인으로 돌려받음 (내림) |
| 상대 | AI(타짜 김씨·홍박사·미스박·광팔이) 또는 온라인 무작위 매칭 |

### 이번 출시에는 — **빼고 나갑니다**

화면의 단추를 지우고, 서버도 그 모드를 안 받게 했습니다(`PICKABLE_MODES`,
`MINI_ON=1` 로만 되살아납니다). 소켓으로 직접 불러도 "알 수 없는 모드" 로
거절되고, 시험(t_minilock)이 실제로 불러 보고 그것을 확인합니다.

그래서 IARC 의 **모의 도박 문항에 "아니요" 로 답합니다.** 판정·화면 코드는
그대로 두었으므로, 규제 정리가 끝나면 그때 되살리면 됩니다 —
**되살리는 날 이 답안도 같이 고쳐야 합니다.**

### 코인을 팔기 시작하면 — 여기가 큽니다
국내에서 **카드·화투류는 웹보드게임으로 따로 규제**합니다.
월 결제한도(2026년 2월 3일부터 100만원), 1회 베팅한도,
하루 손실한도를 넘으면 24시간 이용 제한, 상대 선택 금지 같은 의무가 붙습니다.

지금은 코인을 현금으로 못 사니 대상인지 애매하지만,
**코인을 파는 순간 정면으로 걸릴 가능성이 큽니다.**
코인 판매를 준비할 때 게임물관리위원회 사전상담에서 이 부분을 반드시 물어보세요.

### 줄일 수 있는 선택지
| 안 | 내용 | 값 |
|---|---|---|
| A | 그대로 두고 정직하게 신고 | 등급이 오른다. 코인 판매 때 웹보드 규제 검토 필요 |
| B | 코인 걸기를 빼고 순수 족보 승부로 | 등급·규제 문제가 둘 다 사라진다. 게임성은 크게 바뀐다 |
| C | 이번 출시에서 미니게임을 빼고 나중에 | 가장 빠르고 안전. 설명글에서도 빼야 한다 ← **이걸로 갔습니다** |
